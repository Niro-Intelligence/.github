## Code intelligence for the assistant you already use

On every question, an AI coding assistant greps for names, reads a few files, and guesses the rest of the system. Niro parses your repos into a live map of the whole system: every class, method, call, HTTP hop, event and data store. Your assistant queries that map over MCP, so call chains, blast radius, root-cause analysis and reuse checks become one tool call instead of a guess.

Niro is not a replacement for Claude Code, Cursor or Copilot. It is the deterministic logic layer underneath them.

### Get started

```bash
npm install -g @niroai/niro
niro login          # opens your browser to approve this device
cd ~/code/my-service
niro init           # onboard this folder: create project, upload, build the graph
niro mcp install    # connect one AI assistant, pick it at the prompt
```

Works with 14 assistants, including Claude Code, Cursor, Windsurf, VS Code, GitHub Copilot, Codex and Gemini CLI.
